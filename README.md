# 🌆 City_MD — WhatsApp Bot

> **The City Never Sleeps** — A powerful 50-command multi-user WhatsApp bot built by Scotty.

## Features
- 50 hand-picked powerful commands
- Multi-user web pairing system
- Auto group moderation (antilink, antibadword, welcome, goodbye)
- AI integration (ai, deepseek)
- Media tools (sticker, play, vv, tts)
- Render-ready deployment

## Deploy on Render
1. Fork/upload this repo to GitHub
2. Create a new **Web Service** on [render.com](https://render.com)
3. Set build command: `npm install --legacy-peer-deps`
4. Set start command: `npm start`
5. Add env var: `OWNER_NUMBER = 263788114185`
6. Deploy — visit your URL to pair
